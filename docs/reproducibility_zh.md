# “长期有效归档地址”是什么意思

它就是一个稳定的下载链接，让审稿人和读者在以后仍能找到产生论文结果的那一版材料。只有一个会不断修改的仓库首页，还不足以准确指出实验使用的是哪个版本。

最直接的做法是在 GitHub 仓库创建固定版本的 Release，例如作者自行决定的版本号，并附上相应材料。需要更长期的存档时，也可以把该版本存入能提供持久标识符的研究数据仓库。这里没有替你创建线上发布，也没有生成或杜撰 DOI。

## 应归档哪些文件

1. **最终模型配置**：模型代码的提交编号，网络通道和注意力设置，预处理、图像块尺寸、Adam 学习率、warmup 和重启周期、批量大小、训练轮次、随机种子、验证选模规则、推理阈值等。当前训练程序会保存 `config.json` 和 `environment.json`。
2. **数据划分清单**：每个数据集哪些原始图像用于训练、验证和测试；五折实验则每折各保存一组名单。只需图像标识和相对路径，不必把受原始许可约束的数据集重新上传。本项目使用 `train.json/val.json/test.json`。
3. **实验输出**：实际训练的日志与检查点、每张图的指标 CSV、汇总 JSON，以及计算论文统计表所用的各次独立运行结果。体积较大的权重和概率图可作为 Release 附件或另行存档。
4. **完整性记录**：文件 SHA-256、代码版本、运行命令和环境版本，用来确定读者取得的是哪一份文件。
