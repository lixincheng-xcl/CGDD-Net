# Release Notes

## v1.0.0 — 2026-09-07

Initial public code release for CGDD-Net.

Included:
- full CGDD-Net model;
- CSDE, SAMG, DCDF, selective reconstruction, and CCA;
- seven cumulative ablation variants;
- training, testing, repeated-run, and cross-dataset scripts;
- reproducibility-oriented JSON manifests;
- model profiling and smoke tests.

Datasets and trained checkpoints are not redistributed.
